# Instruções para agentes

Antes de alterar este projeto, leia integralmente `PROJECT_HANDOFF.md`. Ele registra a arquitetura atual, os fluxos administrativos, a configuração de deploy, as variáveis necessárias, o histórico recente e os cuidados que devem ser preservados.

- Não reescreva o histórico Git publicado.
- Não versione artefatos de build.
- Preserve os dados dinâmicos administrados pelo Supabase.
- Execute TypeScript e build antes de concluir mudanças de código.
